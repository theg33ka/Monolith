# KIAS: физические контроллеры и редактор схем

Автоматика KIAS теперь хранится в переносимых карточках и исполняется только в запитанном DATA-шкафу. Добавлены отдельный программатор с нативным редактором и шкаф на восемь физических слотов, с нагрузкой 100 + 25 Вт на вставленную карточку.

Схемы используют строгие типы, логику, сравнения, таймеры и память. Конкретные устройства сохраняют точный UID, ANY выбирает один Online-исполнитель, ALL вызывает каждый один раз; события принимаются от всех подходящих датчиков. WRITE атомарен, сервер проверяет окно, дистанцию, права и ревизию. Грязный черновик защищён от случайного извлечения.

Все 27 прежних протоколов представлены обычными редактируемыми graph presets. Старый исполнитель и редактор выведены из игрового пути; старые записи доступны для явного импорта на переходный период. Без карточек программные действия не выполняются. Тяжёлые алгоритмы ПКО и безопасные API устройств сохранены. DeviceLink-мост наблюдает source без провода и использует штатную защиту sink от перегрузки.

Исполнение использует индексы, ограниченные очереди и общий планировщик. OFF, потеря DATA/питания и извлечение отменяют работу. Обратная связь через устройства и исключения исполнителей изолируются на карточке. Карты сохраняют программу, слоты и конкретные привязки, с восстановлением UID.

Проверка: 46 тестов KIAS, включая все шаблоны, native layout, безопасность редактора, реальную нагрузку/слоты, перенос, сохранение, ANY failover/ALL exactly-once и отмену после Shutdown/OFF. Нагрузочный стенд включает восемь карточек в одном шкафу и 207 схем по 100 узлов/200 проводов на 200 гридах. Точные max/p95, allocations и пределы результатов приведены в [VALIDATION](VALIDATION.md).

Спрайты: Hurtsay for Forge, CC-BY-SA-3.0, PNG не изменены. Внешние референсы изучены без копирования DM/React/Factory кода; [атрибуция](THIRD_PARTY.md).

Живая ручная сессия и игровые скриншоты не приложены. Локальный фикс TabContainer и его тесты остаются отдельной работой RobustToolbox; gitlink этим патчем не меняется.
