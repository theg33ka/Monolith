## О PR

Исправляет игровой путь настройки KIAS: WRITE переносит название программы на физическую карточку, ALL Speaker произносит текст от каждого выбранного динамика, а интегрированные лампы остаются доступными для включения после OFF. Добавлен прямой профиль «Освещение»; существующий `LightController` сохранён для контроллеров групп.

Редактор показывает настройки по возможностям узла, значения на схеме, именованные перечисления и описания каждого порта. Окна программатора, шкафа, сервисного инструмента, устройств и управления получили рамки, переносы, подсказки и вертикальную прокрутку. Дополнены русские и английские названия/описания KIAS.

Дополнительно устранён бесконечный пересчёт сети при незакреплённом атмосферном устройстве рядом со сканером подключения. Кнопки шкафа сохраняют фокус при обновлениях, подсказки портов закрываются сразу при уходе курсора. Подробности — [UI_STABILITY.md](UI_STABILITY.md).

Добавлены обнаружение опасной фауны без персонажа рядом, модуль угроз в новом продвинутом сканере и режим мониторинга выходов у диагностического инструмента. Кириллица проверена через клиентский редактор, WRITE и речь динамиков; ядро получило отдельный спрайт 32×64. Подробности — [FAUNA_MONITOR.md](FAUNA_MONITOR.md).

## Зачем / Баланс

Убирает случаи, когда возможность была недоступна игроку: выключенную лампу нельзя было включить, мультитул вместо списка AirAlarm переключался на порты, а одно объявление подавляло остальные динамики. Лимиты схем и cooldown объявлений сохранены.

Сервисный инструмент явно хранит Group отдельно от Message, показывает текущую группу и обновляет выборки после назначения. Штатный список sensor/vent/scrubber снова настраивается через List; цепочка Danger/AtmosDanger и восстановление AtmosClear покрыты тестом.

## Как тестировать

Итоговый прогон: 79/79 (69 тестов KIAS и 10 проверок штатных портов). Предыдущие проходы: 71/71 и 58/58. Команда, реальные сценарии и ограничения проверки описаны в [VALIDATION.md](VALIDATION.md); причины и список затронутых файлов — в [CORRECTION_REPORT.md](CORRECTION_REPORT.md).

В игре: Rename → WRITE → извлечь карточку; собрать String + OnStart → Speaker и ALL Speaker; выключить/включить интегрированный свет; назначить группу лампе/контроллеру/динамику; обычным мультитулом List добавить атмосферные устройства к AirAlarm и вызвать разгерметизацию, затем восстановить газ.

## Ломающие изменения

Версия программы остаётся 1, прежние prototype/profile IDs сохранены. Старые enum-константы получают домен из подключённых портов. Если одна константа раньше обслуживала разные известные enum-домены, разделить её на отдельные константы: редактор теперь сообщает о несовместимости. Старые группы инструмента из Message восстанавливаются при загрузке.

Единственное общее изменение — `NetworkConfiguratorSystem.DetermineMode`: устройства с DeviceNetwork и DeviceLink сохраняют выбранный List/Link вместо принудительной смены режима. Удаление портов только у KIAS сломало бы интеграцию; регрессия обычного AirAlarm → light без KIAS проходит.
