# КИАС: реализация и проверка

КИАС реализована на линии `main`, исходный коммит `b069ad386d7599ac6b51d9dfcdfba9b6a311f676`. Документ фиксирует объём реализации и результаты локальной проверки от 7 октября 2026 года.

## Реализовано

- Одно ядро на грид; детерминированный отказ при нескольких ядрах; индексы устройств, кабелей, экипажа и датчиков с обработкой питания, перемещения, разделения и удаления грида.
- Отдельный DATA-кабель: кардинальные связные участки, радиус обслуживания две клетки, кеширование топологии и одно отложенное перестроение на изменение. Поворот орудия сеть не перестраивает.
- Серверы обороны, атмосферы, питания, экипажа, навигации и переносимый сохраняемый регистратор на 64 записи. OFF сначала объявляется, затем исключает корабль из всех периодических обработчиков; ON заново регистрирует сеть.
- Сканер с шестью реальными слотами модулей; центральная обработка индексированных тел примерно раз в секунду. Игроки, мёртвые/оставленные тела, борги, химеры и разумные артефакты учитываются; обычные NPC исключаются.
- Отдельный транспондер 1×1 с сохраняемым UUID, регистрацией ЛКМ и блокировкой по умолчанию. Изменять блокировку может владелец. Перекрывающиеся сканеры и повторная регистрация не удваивают Crew.
- Семь страниц дисплея, строка `Entities: N // Crew: M`, состояния устройств и индикация серверных/настенных модулей. Закрытые дисплеи не собирают и не отправляют полный UI-снимок.
- Мультитул: связь, диагностика, цветной снимок покрытия DATA, TEST, группы света/динамиков, названия помещений. Текст связи сохраняется с UID и портом источника. TEST длится пять секунд, имеет перезарядку десять секунд и восстанавливает прежний контекст.
- Событийные мосты воздушных/пожарных тревог, роста аномалии, FTL и автопилота. Спектральная тревога возникает на пересечении порога вверх и содержит местоположение. Horizon работает примерно до двух километров и использует штатные IFF/фракции/компании.
- Физические попадания в корпус, повреждения/разрушения конструкций, столкновения гридов с порогом и дедупликацией. Поглощение щитом не считается попаданием в корпус.
- Группы штатных светильников; реальная водяная пена с расходуемым и перезаряжаемым картриджем.
- Реле HV/MV/LV/DATA действительно размыкает только выбранную сеть через штатные узлы питания и кеш DATA. Состояние сохраняется; открытое DATA-реле можно закрыть локально.
- Мониторинг штатной электросети с ограниченной частотой и уведомлением на переходе в дефицит. Нагрузку сбрасывают только настроенные игроком действия.
- ПКО: индекс корабельных снарядов, общие пространственные корзины, траектория/упреждение, временная резервация L85, реальные FireControl/Gun, патроны, питание, перезарядка и пересечение траектории настоящим выпущенным снарядом. Ручной огонь блокируется на время резервации с объяснением; освобождение возвращает прежние координаты прицеливания.
- Детектор выстрелов по событию с сектором 90° и подавлением повторов; датчик сближения с пространственным поиском раз в секунду и сохранением текущих контактов при постороннем изменении топологии.
- Ограниченные протоколы, условия IFF/числового порога/отсутствия дееспособного зарегистрированного экипажа, ручной запуск и сброс тревоги владельцем. Штатные записи боевой тревоги включают EMERGENCY и ПКО; настройка дополнительных действий доступна на дисплее.
- MAYDAY: штатная радиосеть, перезарядка 60 секунд, совместимая метка IFF и журнал. Отсутствие экипажа само по себе медицинскую помощь не вызывает.
- Машинные/компьютерные платы, обычные рамы и рецепты автолата/принтера плат; русская и английская локализация.

## Исправления по игровому тесту пользователя

После завершения исходного пакета исправлены две отдельно сообщённые проблемы:

1. Звук больше не проходит через преобразование `SoundPathSpecifier.ToString()` в путь метода глобального объявления. Используется штатный `SharedAudioSystem.PlayPvs` с корневым ресурсным путём.
2. Динамики говорят штатной локальной речью от собственного UID. Клиент получает локальное сообщение, имя устройства и чат-бабл над динамиком. Общекорабельное событие передаётся всем подключённым динамикам, группа/устройство ограничивают адресатов; прямая связь говорит только через свой приёмник.

Отдельная проверка с подключённым клиентом прошла: предупреждение со звуком, локальный источник сообщения, адресная группа, текст прямой связи и отсутствие новых сообщений при OFF. Уже звучащий сигнал останавливается при OFF, потере связи и удалении динамика.

## Проверки

Контроль исходного пакета: **32 прошли, 2 штатных теста питания пропущены, 0 ошибок** (19 проверок КИАС плюс штатные PowerTest). Пропущены существующие `TestBatteryRamp` и `TestSupplyRamp`. Сборка включает Shared, Server, Client, XAML, загрузку YAML и локализации.

После изменения речи/звука: **33 прошли, 2 штатных теста питания пропущены, 0 ошибок** (35 проверок). Дополнительный контроль остановки сирен: **20/20 проверок КИАС прошли**. Регрессия речи и звука проверена с подключённым тестовым клиентом. Команда:

```powershell
dotnet test Content.IntegrationTests/Content.IntegrationTests.csproj --no-restore -c Debug -m:2 --filter 'FullyQualifiedName~KIAS|FullyQualifiedName~Content.IntegrationTests.Tests.Power.PowerTest' --logger 'console;verbosity=normal'
```

Проверены реальные четыре силовые/информационные сети, сохранение/загрузка UID-ссылок и пользовательского текста, настоящий выстрел/перехват, штатное поглощение щитом, разделение грида, потеря питания, перемещение, истечение TEST, владелец/чужой актор/чужой грид, игрок в химере/артефакте, UI и критерий медицинской помощи.

## Нагрузочный стенд

200 настоящих игровых гридов, по 10 DATA-кабелей; 800 индексированных тел; до 500 снарядов. Это локальный headless-стенд с игровым движком и тестовым клиентом. Значения одного контрольного запуска, а не нормативы производственного сервера.

| Сценарий | Время | Выделение памяти |
|---|---:|---:|
| 200 простаивающих активных ядер, 60 полных тактов | 135 мс | 4.07 МБ суммарно |
| 200 сканеров / 800 тел, 60 тактов | 247 мс | 19.40 МБ суммарно |
| 1 радар / 10 снарядов, 60 тактов | 87 мс | 2.98 МБ суммарно |
| 50 радаров / 200 снарядов, 60 тактов | 250 мс | 7.30 МБ суммарно |
| 200 радаров / 500 снарядов, 60 тактов | 500 мс | 13.94 МБ суммарно |
| 200 радаров / 0 снарядов, 60 тактов | 89 мс | 2.98 МБ суммарно |
| 200 оснащённых кораблей OFF, 60 тактов после прогрева | 53 мс | 2.39 МБ суммарно |
| 200 включений / перестроений | 8.5 мс | 2.60 МБ в серверном потоке |
| 200 FTL-прибытий | 151 мс | 23.27 МБ в серверном потоке |
| 200 пересечений порога аномалии | 5.1 мс | 0.57 МБ в серверном потоке |
| 200 разрывов / перестроений | 30 мс | 7.03 МБ в серверном потоке |
| 200 восстановлений / перестроений | 48 мс | 8.38 МБ в серверном потоке |

Полные такты включают остальные игровые системы, клиент и тестовую обвязку. Первый холодный замер OFF включал прогрев и создание состояния: 476 мс / 95 МБ. Сравнивать его напрямую с последующими прогретыми замерами нельзя.

Исправление обновления закрытых дисплеев сократило серию 200 FTL-прибытий с примерно 551 мс / 163 МБ до 151 мс / 23 МБ на этом стенде. Отдельный чистый стенд топологии также покрывает 200 гридов / 20 000 кабелей.

Краткая инструкция игроку: [руководство игрока](PLAYER_GUIDE.md). Визуальная проверка всех страниц в полноценном игровом окне и проверка на публичном сервере не проводились; пользователь уже выполнил собственную игровую пробу. Полный набор тестов всего репозитория не запускался.
