# Разработка и поставка KIAS

KIASDev — рабочая ветка системы, лаборатории, нагрузочных сценариев и ревью. KIAS — готовые игровые изменения и обычные регрессионные тесты. Обе включают main форка theg33ka/Monolith на момент разделения.

Готовые исправления игрового кода и изменения лаборатории оформляются отдельными коммитами. Для выпуска переносите выбранные готовые коммиты в KIAS через cherry-pick или отдельную ветку патча. Слияние всей KIASDev может добавить отчёты и лабораторные файлы либо вызвать modify/delete-конфликты; состав патча нужно проверять перед публикацией.

В KIAS сохраняются проверки графов, сетей, доступа, устройств и лимитов очередей. Лабораторная карта Briar, нагрузочные тесты, профилирование времени, Tools/KiasBenchmark и корневые запускатели находятся в KIASDev.

Run_KIAS_Tests.bat -CheckOnly проверяет готовность стенда. Новая нагрузочная серия запускается только по явной команде пользователя. Проверка или сборка не разрешает автоматически отправлять START.

KIAS_REVIEW/01–07 и baseline-source фиксируют исторические снимки независимого ревью. Их старые команды восстановления не предназначены для повторного выполнения поверх новых веток. Сведения о разделении веток находятся в KIAS_REVIEW/08_BRANCH_PUBLICATION.md. Полные сырые результаты и журналы переданы владельцу отдельным архивом; в Git оставлены отчёты, исходники доказательств и восстановимые патчи.
