# KIAS v3 — финальный пакет ТЗ для агента

**Сначала** `00_MASTER_PROMPT.md`; затем `11`—`14` (переопределяют конфликтующие пункты v2) и остальные файлы. Пакет содержит v2 документацию как контекст и точные дополнения по двум изображениям пользователя, runtime/physics и финальному BAT. Текущий `KIAS` HEAD удалённой ветки при подготовке в предыдущей проверке: `97178c6` (историческая точка); агент обязан сверить локальный HEAD и последний архив результата.

Главный пользовательский сценарий: агент проводит оптимизации и короткий префлайт, **не запускает долгий финальный тест**; сообщает `READY_FOR_USER_FULL_RUN`; пользователь запускает `Run_KIAS_Tests.bat` и получает полный 40-корабельный игровой тест с прогрессом, ETA и всеми бинарниками / логами. Внешний сканер видит ограниченную нерегулярную зону снаружи борта, внутренний (-11,2) обязан правильно определить комнату без изменения briarKIAS.yml. Два рисунка — эталон ожидаемой геометрии, запросить/использовать их в локальной среде для точной визуальной проверки.

**При конфликте:** v3 `00, 11–14` первичны; v2 01–10 действуют лишь если не противоречат v3. Главный исправленный конфликт — v2 требовал агенту самому выполнить долгий FullGame; теперь долгий FullGame запускает только пользователь.
